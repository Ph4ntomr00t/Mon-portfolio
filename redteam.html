Red Team vs Pentest

Le Red Teaming va au-delà du pentesting traditionnel : il s'agit de simuler un adversaire réel avec des objectifs spécifiques, en utilisant des TTP (Tactics, Techniques, Procedures) d'acteurs malveillants, tout en évitant la détection des équipes bleues.

🎭

Kill Chain Methodology

Phase 1

Reconnaissance

OSINT gathering, infrastructure mapping, employee enumeration, technology stack identification, security posture assessment, social engineering vectors.

Phase 2

Initial Access

Phishing campaigns, drive-by compromise, supply chain attacks, public-facing application exploitation, valid accounts compromise.

Phase 3

Execution & Persistence

Command execution via various methods, malware deployment, persistence mechanisms establishment, backdoor installation, scheduled task creation.

Phase 4

Privilege Escalation

Local privilege escalation, exploitation of misconfigurations, token manipulation, UAC bypass, kernel exploits when necessary.

Phase 5

Defense Evasion

EDR/AV bypass, log manipulation, indicator removal, process injection, obfuscation, timestomping, disabling security tools.

Phase 6

Credential Access

LSASS dumping, SAM/NTDS extraction, Kerberos ticket extraction, credential phishing, keylogging, password spraying attacks.

Phase 7

Discovery

Network enumeration, Active Directory reconnaissance, BloodHound analysis, system/user/group discovery, sensitive data location.

Phase 8

Lateral Movement

Moving between systems, remote services exploitation, pass-the-hash/ticket attacks, RDP/SSH hijacking, exploitation of trust relationships.

Phase 9

Collection & Exfiltration

Data collection from various sources, staging for exfiltration, covert channels, data compression, encrypted exfiltration paths.

Phase 10

Impact & Objectives

Achieving defined objectives (flag capture, data access, domain compromise), demonstrating potential impact, documentation for reporting.
