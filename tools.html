Mes projets et outils

Ce sont mes premiers outils et scripts développés pour m’entraîner, expérimenter et progresser en sécurité. Tout est open-source et conçu pour apprendre la reconnaissance, l’énumération et le pentesting de base.

🛠️ Outils Développés

ReconJunior

Petit script Python pour faire de la reconnaissance simple : scan de ports, découverte de sous-domaines et reporting de base.

Python Recon

MiniShell

Reverse shell basique pour comprendre les communications entre client et serveur. À utiliser uniquement dans mes labs et environnements de test.

Python Shell

ADEnum Lite

Petit outil pour m’exercer à l’énumération Active Directory et découvrir les bases de BloodHound et des credentials.

PowerShell AD Enumeration

WebFuzzer Junior

Fuzzer simple pour m’entraîner sur les applications web et comprendre les injections et la découverte de fichiers sensibles.

Python Fuzzing Web
